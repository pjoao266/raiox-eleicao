# Raio-X 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Publicar painel de votação por candidato em raiox2026.joaomelo.space.
**Architecture:** React + Tailwind com API TypeScript em Cloudflare Workers. Coleta retomável em lotes e cache persistente; configurações e resultados oficiais TSE.
**Tech Stack:** React, Tailwind, TypeScript, Cloudflare Workers, R2 para cache de arquivos e resultados.
**Spec:** docs/superpowers/specs/2026-10-08-raiox2026-design.md

## Global Constraints
- Top/bottom 10 municípios; top/bottom 3 estados somente para presidente.
- Consolidado Brasil para presidente; UF para demais cargos.
- Exterior separado dos rankings; percentuais oficiais e zero diferente de ausente.
- Lotes retomáveis, concorrência limitada, cobertura parcial explícita.
- DNS já na Cloudflare; confirmar implantação e domínio antes de afirmar sucesso.

## Review Focus
- Mesmo número de candidato em UFs diferentes: identificar por eleição/cargo/sqcand.
- JSON ausente ou 404: cobertura parcial sem substituir por zero.
- UF/cargo/turno indisponível: bloquear seleção inválida.
- Mudança de candidato durante coleta: descartar respostas da seleção anterior.
- Cache desatualizado: mostrar data e permitir atualização, sem afirmar ranking definitivo.
